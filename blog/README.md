# Swift Signing Florida Blog Starter

This package contains:

- `blog/index.html`
- 10 complete article pages
- `blog-additions.css` with only the new blog styles
- `resources-page-snippet.html` for linking the existing Resources page to the blog

## Install

1. Copy the entire `blog` folder into the root of your project.
2. Append the contents of `blog-additions.css` to the end of your existing `styles.css`.
3. Add the snippet from `resources-page-snippet.html` to `resources.html`.
4. Create `/images/og-blog-life-insurance.jpg` for social sharing, or change the Open Graph image path in the blog files.
5. The article pages include a commented YouTube embed. After publishing each video, replace `YOUR_VIDEO_ID` and remove the surrounding HTML comment markers.
6. Test locally through Live Server and then deploy to Netlify.
